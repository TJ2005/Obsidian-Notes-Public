# Mobile Application Development Lecture 1

## Android Platform
- Open source etc
- Android was developed by the Open Handset Alliance, led by Google, and other companies
- Linux-based operating system
- offers a unified approach to application development
- Apps are able to run on different devices powered by Android

## Features of Android
- Premade good lookin UI
- connectivity
	- GSM, IDEN, CDMA, WiFi, LTE, Etc.
	- Storage
		- SQLite
	- Media Support
	- Messaging
- Web browser
- Multi Touch
- Multi Tasking
- Resizable widgets
- Multi-Language
- GCM
	- Google Cloud Messaging
- WiFi Direct
- Android beam
	- NFC
