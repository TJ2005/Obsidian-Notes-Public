# 📄 **Paging in Operating Systems**

## ✅ **Definition**

Paging is a memory management scheme in operating systems that eliminates the need for contiguous allocation of physical memory. It allows the physical address space of a process to be non-contiguous, making efficient use of memory and reducing fragmentation.

---

## 🛠️ **Key Concepts**

### 1. **Physical Address Space (PAS)**

- The actual memory addresses in the hardware (RAM).
    
- It refers to the set of addresses that the memory management unit (MMU) uses to access data.
    
- Divided into **fixed-size blocks** called **frames**.
    

### 2. **Logical Address Space (LAS)**

- The address generated by the CPU during program execution.
    
- Also known as **virtual address space**.
    
- Divided into **pages** of the same size as frames.
    

---

## 🔥 **How Paging Works**

1. **Division of Memory**
    
    - **Logical Memory (Process)** → Divided into **pages**.
        
    - **Physical Memory (RAM)** → Divided into **frames**.
        
    - Page size = Frame size.
        
2. **Page Table**
    
    - A data structure that maps **logical addresses** (pages) to **physical addresses** (frames).
        
    - Each **page table entry (PTE)** contains:
        
        - **Frame number** → Corresponding physical frame.
            
        - **Valid/Invalid bit** → Indicates if the page is in memory or on disk (swap).
            
3. **Address Translation**
    
    - **Logical Address (Page number + Offset)** → Mapped to **Physical Address (Frame number + Offset)**.
        
    - Formula:  
        Physical Address=(Frame number×Frame size)+Offset\text{Physical Address} = (\text{Frame number} \times \text{Frame size}) + \text{Offset}
        

---

## 📚 **Advantages of Paging**

- **Eliminates external fragmentation**: Memory is allocated in fixed-sized frames, preventing fragmentation.
    
- **Efficient memory utilization**: Multiple processes can reside in different parts of physical memory.
    
- **Easy to implement**: Fixed-size frames simplify memory management.
    

---

## ⚠️ **Disadvantages of Paging**

- **Internal fragmentation**: Occurs when a process does not fully utilize the allocated frame.
    
- **Overhead**: Maintaining page tables requires additional memory and increases lookup time.
    
- **Page faults**: When a required page is not in RAM, a **page fault** occurs, leading to disk access, which is slow.
    

---

## 🛠️ **Paging vs. Segmentation**

|Feature|Paging|Segmentation|
|---|---|---|
|Memory Division|Divides memory into fixed-size pages|Divides memory into variable-size segments|
|Fragmentation|Internal fragmentation occurs|External fragmentation occurs|
|Addressing|Page number + offset|Segment number + offset|
|Protection|Same protection for all pages|Protection per segment|

---

✅ **Use Case:** Paging is used in modern operating systems such as **Windows**, **Linux**, and **Unix** to implement **virtual memory**, enabling processes to use more memory than physically available.
