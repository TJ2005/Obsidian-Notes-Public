# Introduction to Network Security

### Passive Traffic Analysis
Passive traffic analysis is a method of monitoring network traffic to gain information without altering the data in any way. Mostly focuses on breaking confidentiality. It is often used for:
- **Network Monitoring**
- **Performance Management**
- **Security Analyst**
### Active Attacks
Active attacks involve an attacker attempting to alter, disrupt, or gain control over network resources or data. Breaks the entire CIA Triad. It is often These attacks can be categorized into several types.
- **DDOS Attack**
- **Man-in-the-Middle (MitM) Attacks**
- **Phishing**
- **SQL Injection**
