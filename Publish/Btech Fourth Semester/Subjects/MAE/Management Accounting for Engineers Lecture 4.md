# Maximum Level
Maximum Level = Re order level + re order qty - min rate of consumption $\times$ min re order period

Minimum Level = Re-order level  - ( normal rate of consumption ) $\times$ Normal re order period.

Re order level = Max rate of consumption $\times$ Max Re order period lead time
