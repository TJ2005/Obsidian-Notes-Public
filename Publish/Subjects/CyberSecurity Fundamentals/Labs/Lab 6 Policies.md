# Lab 6 Policies
**Experiment 6: Information Security Policy**
**Aim:**
To create an information security policy for the given scenario.

**Learning Outcomes:**
After completing this experiment, I should be able to:

1. Understand various types of security policies and their scope.
2. Create an acceptable use policy for a given scenario.

**Theory:**
Security policies are written rules for protecting an organization's information, systems, and assets. They guide employees, contractors, and users to secure data and prevent breaches. Policies are higher level than standards and procedures.

**Policy Attributes:**

1. Must be followed by all users.
2. Non-compliance can lead to disciplinary action.
3. Focus on what is to be achieved, not how.
4. Defined further by standards and guidelines.

**Types of Security Policies (NIST SP 800-12r1):**

* **Program Policy:** Creates an organization's overall security program.
* **Issue-specific Policy:** Deals with specific concerns (e.g., email usage).
* **System-specific Policy:** Protects a particular system (e.g., online learning platform).

**Procedure:**

1. **Scenario:** SVKM’s NMIMS is a mid-sized academic institution with 40,000 students, faculty, and staff. It manages student records, research data, online learning platforms, and administrative systems. Sensitive data includes grades, financial aid, and research. To comply with laws like DPDPA, the university leadership wants a formal information security policy. As CISO, I am required to draft an Enterprise Information Security Policy (EISP).
2. Created a Word document for the policy and uploaded it on MS Teams.

**Questions & Answers:**

1. **What is a security policy, and why is it important?**
   A security policy is a set of rules for protecting information and systems. It is important because it prevents data breaches, ensures compliance with laws, and guides users on safe practices.

2. **Explain various types of information security policies with an example:**

* **Program Policy:** Overall security program (e.g., university-wide policy on protecting student records).
* **Issue-specific Policy:** Addresses a particular issue (e.g., acceptable use of email and internet).
* **System-specific Policy:** Protects a specific system (e.g., security rules for the online learning platform).

3. **Supporting policies required for EISP and their purpose:**

* **Acceptable Use Policy (AUP):** Defines how users can access university systems safely.
* **Password Policy:** Ensures strong passwords to prevent unauthorized access.
* **Data Classification Policy:** Labels data by sensitivity to apply appropriate controls.
* **Backup and Recovery Policy:** Ensures data can be restored in case of loss.
* **Incident Response Policy:** Guides staff on responding to security incidents.

4. **How are policies different from standards, guidelines, and procedures?**

* **Policies:** High-level rules about what must be done.
* **Standards:** Mandatory rules to meet policy requirements.
* **Guidelines:** Recommendations to follow best practices.
* **Procedures:** Step-by-step instructions to implement policies.
