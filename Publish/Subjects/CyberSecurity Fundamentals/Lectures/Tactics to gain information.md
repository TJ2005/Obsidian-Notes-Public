### Phishing
- **Method of Attack**: Gain trust and misuse it to gain information; trick individuals into providing sensitive information.
- **Common Techniques**: Fraudulent emails, fake websites, misleading communications.
- **Goals**: Steal sensitive information, distribute malware, gain unauthorized access.
- **Prevention/Defense**: Verify sources, avoid clicking suspicious links, use multi-factor authentication, educate and use security software.

### Spoofing
- **Method of Attack**: Impersonate a trusted source to gain access or information.
- **Common Techniques**: Web spoofing, email spoofing.
- **Goals**: Deceive users into revealing sensitive information, spread malware.
- **Prevention/Defense**: Check URL authenticity, use email authentication methods, be cautious of unsolicited communications.

### Malware
- **Method of Attack**: Use malicious software to harm or exploit any programmable device.
- **Common Techniques**: Host device to victim device transmission.
- **Goals**: Damage systems, steal data, gain control of systems.
- **Prevention/Defense**: Use antivirus software, keep systems updated, avoid downloading unknown files.

### Advanced Persistent Threat (APT)
- **Method of Attack**: Prolonged and targeted cyberattacks.
- **Common Techniques**: Custom malware, zero-day exploits, persistent access methods.
- **Goals**: Steal data over a long period, monitor target activities.
- **Prevention/Defense**: Advanced threat detection systems, regular security audits, network monitoring.

### Botnet
- **Method of Attack**: Network of infected devices controlled by a single attacker.
- **Common Techniques**: Malware infections, command and control servers.
- **Goals**: Conduct DDoS attacks, send spam, steal data.
- **Prevention/Defense**: Use firewalls, keep software updated, monitor network traffic.

### Denial of Service (DoS)
- **Method of Attack**: Overwhelm systems, networks, or services with traffic to disrupt normal operations.
- **Common Techniques**: Flood attacks, crash attacks.
- **Goals**: Make services unavailable, cause operational disruption.
- **Prevention/Defense**: Use DoS protection services, configure network hardware against attacks, monitor traffic.

### Network Threats
- **Method of Attack**: Exploit vulnerabilities in network infrastructure.
- **Common Techniques**: Eavesdropping, man-in-the-middle attacks.
- **Goals**: Intercept data, alter communications, gain unauthorized access.
- **Prevention/Defense**: Use encryption, secure network configurations, regular security assessments.

### Drive-by Downloads
- **Method of Attack**: Automatically download malicious software to a user's system without their consent.
- **Common Techniques**: Exploit vulnerabilities in websites or web browsers.
- **Goals**: Infect systems with malware, steal data.
- **Prevention/Defense**: Keep software updated, use web protection tools, avoid suspicious websites.

### Misleading Applications
- **Method of Attack**: Trick users into installing applications that appear legitimate but have malicious intent.
- **Common Techniques**: Fake software updates, deceptive advertisements.
- **Goals**: Steal information, gain control of systems.
- **Prevention/Defense**: Download software from trusted sources, verify application authenticity, use security software.
