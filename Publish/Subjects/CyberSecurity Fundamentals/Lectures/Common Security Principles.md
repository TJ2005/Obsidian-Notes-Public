# Common Security Principles
- Separation of priviliges
	- Cheque Maker and checker
	- Can Just make and Authorize the cheque 
- Least Priviliges
	- Only provide that much privilege that is required to complete the task.
	- No more No less
	- Example Tea
- Defence In Depth
	- Defenses should be Layered.
	- One part failure should have a fallback for security
- Security through Obscurity
	- The service is not known to run or expected to be in such places where it is at
- Fail Safe Defaults
- Economy of Mechanism
	- Do u just add a ID Swiper on all floors just for security? no
- Complete Mediations
- Least Common Mechanism
- Considering Security Tradeoffs
